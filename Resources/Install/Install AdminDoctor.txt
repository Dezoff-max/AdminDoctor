AdminDoctor Installation / Установка AdminDoctor
==========================================

English
-------
1. Drag AdminDoctor.app to Applications.
2. Open AdminDoctor from Applications.
3. If macOS blocks this unsigned build, allow only this app instead of
   turning Gatekeeper off:
   - macOS 15 and later: try to open AdminDoctor.app once, then go to
     System Settings > Privacy & Security, scroll to Security, and click
     Open Anyway next to the AdminDoctor message.
   - macOS 13 and 14: Control-click AdminDoctor.app, choose Open, then
     confirm Open.

Do not disable Gatekeeper system-wide to run AdminDoctor.

AdminDoctor does not upload telemetry and does not run sudo commands itself.

Русский
-------
1. Перетащите AdminDoctor.app в папку «Программы».
2. Запустите AdminDoctor из папки «Программы».
3. Если macOS блокирует неподписанную сборку, разрешите запуск только
   этого приложения, не отключая Gatekeeper:
   - macOS 15 и новее: попробуйте открыть AdminDoctor.app один раз, затем
     откройте «Системные настройки» > «Конфиденциальность и безопасность»,
     прокрутите до раздела «Безопасность» и нажмите «Всё равно открыть»
     рядом с сообщением об AdminDoctor.
   - macOS 13 и 14: Control-click / правый клик по AdminDoctor.app,
     выберите «Открыть», затем подтвердите «Открыть».

Не отключайте Gatekeeper для всей системы ради запуска AdminDoctor.

AdminDoctor не отправляет телеметрию и сам не запускает sudo-команды.
